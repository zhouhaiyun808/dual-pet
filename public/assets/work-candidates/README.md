# 工作美术母帧归档

正式母帧：

- `solo-chen.png`：陈子奚单人批注
- `solo-jiang.png`：江晏单人研习
- `dual-jiangchen.png`：双人共同工作

三张图均为 1024 × 536 RGBA。原先由 `src/work-scene.ts` 绘制的矩形闭眼、程序墨迹和多边形翻页已经删除。正式运行资源已经移至 `../work-frames/`，工作状态只切换独立透明 PNG。

单人工作状态分别读取对应单人母帧；组合后的共同工作状态读取双人母帧。设置页只提供三种静态母帧预览。

## 生成探索记录

曾用内置 imagegen 尝试把母帧扩展为关键帧，要求固定人物、桌案、镜头与透明背景。早期不合格试产没有纳入项目；正式帧均已通过尺寸、真实 alpha 与固定锚点检查。
