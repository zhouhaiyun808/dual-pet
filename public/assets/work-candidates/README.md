# 工作美术：待用户验收

`keyframes.png` 是 imagegen 内置工具生成的造型候选：陈子奚批注、江晏研习、双人桌。它有背景光晕，尚不满足正式透明精灵要求，不加载进桌宠。没有替换原始人物素材。

应用当前使用 `src/work-scene.ts` 的临时固定锚点组合：原始站定人物、像素桌面、翻页/批注图层，供逻辑联调。它不是最终通过验收的工作动画。

面对面资源通过 `getStaticFrame(id, 'face-left' | 'face-right')` 引用原左右行走第一帧，保留江晏素材左右映射修正，不引用亲亲帧。

验收顺序：用户审看人物/桌面静态图 → 根据反馈修订正式透明资源 → 制作最终循环 → 用户真机验收节奏和比例。等待验收期间核心逻辑继续开发。

## 生成提示词摘要

内置 imagegen，以两张 source-sheet 为角色和像素风格参考。三行静态工作关键帧：绿色内衫紫灰外袍陈子奚在短木桌读书批注，蓝衣江晏研读武学，二人共用长桌。正视角、全身与桌腿、保留发型配色比例、书与笔、透明背景、无文字。首轮生成后又尝试仅去背景与光晕，但未取得合格透明结果，因此保持为候选。
