# UI 与成长系统实施进度

## 阶段 1：成长数据与迁移（已完成）

- 新增全局共享 `bond`，含总值、日期和独立的每日 `800` 上限。
- 宠物进度对外统一为 `personalGrowth`；旧存档 `intimacy` 作为兼容别名读取。
- 旧存档的共享羁绊取两只宠物旧亲密度的较小值，个人成长、阶段、收藏和事件记录保留。
- 单人时间、个人输入和番茄钟仅增加个人成长；共同互动只增加一份共享羁绊，同时两人各自获得个人成长。
- 阶段阈值改为读取共享羁绊，并保留睡眠、面对面对话、共同工作和亲亲事件条件。

## 阶段 2：设置页与今日页（已完成）

- 页签改为“片语 / 今日 / 成长 / 设置”，默认进入“今日”，保留键盘导航与 ARIA 关联。
- 今日陪伴改为“陈子奚 / 两人羁绊 / 江晏”三栏，只在中间显示一组心形。
- 今日输入改为两侧个人统计、中间键盘与点击合计，并继续使用防回退的实时计数快照。
- 陈子奚两处头像统一改用从三视图正面无损裁出的 `portrait-front.png`。
- 删除保存与撤销按钮；复选框即时保存，分钟输入 400ms 防抖并在失焦时校验保存。
- 无效分钟值保留在输入框并显示范围提示；保存期间的新修改通过编辑版本继续排队，不会被旧响应清除。
