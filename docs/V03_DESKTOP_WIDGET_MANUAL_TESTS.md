# 桌面轻量挂件手动验收

| 编号 | 操作 | 预期结果 |
|---|---|---|
| W01 | 两人分别站立并保持默认显示 | 陈、江头顶各有一份挂件，番茄钟与设备级键鼠总数一致 |
| W02 | 关闭陈的挂件 | 只隐藏陈的挂件，江不受影响 |
| W03 | 右键陈并选择“显示桌面信息挂件” | 只恢复陈的挂件，菜单文案随后变为“隐藏桌面信息挂件” |
| W04 | 让两人进入双人状态 | 单人挂件隐藏，只在两人中间显示一份双人挂件 |
| W05 | 关闭并右键恢复双人挂件 | 只影响居中的双人挂件；拆分后恢复两人此前的单人显隐状态 |
| W06 | 开始、暂停、继续与结束番茄钟 | 挂件内按钮可直接暂停／继续，hover 与按下热区准确；DSEG 倒计时清晰；按钮+阶段+时间整体居中，宠物脚底不跳动 |
| W07 | 分别输入键盘和鼠标 | 两项设备级总数独立增加，多份挂件不会重复累计 |
| W08 | 触发单人及双人台词 | 台词挂在当前说话人头顶，连续对话逐句出现且不重叠 |
| W09 | 触发休息提醒 | 单人分开时两边各一份；双人状态仅在两人中间一份，并有限脉冲三次 |
| W10 | 检查应用菜单、设置页和构建文件 | 不存在旧“今日操作计数面板”入口或独立窗口 |
| W11 | 分别触发陈、江的最长台词 | 文字完整、无滚动条；泡泡只增高中间宣纸段，松竹、四角、尾尖不拉伸且不压字 |
| W12 | 观察无台词→有台词→无台词 | 无台词时挂件紧贴人物上方；有台词时挂件上移腾出空间；消失后回落，人物脚底锚点不变 |

Windows 与 macOS 都需覆盖 W01–W12；Windows 本轮还必须按 `V03_WINDOWS_WIDGET_ACCEPTANCE.md` 执行完整回归。
