### 关键结算顺序

`runtime.rs` 全局锁序固定为 **Session/Core → input**。`with_batch` 在同一输入临界区内先取出已有键鼠增量、结算旧在场集合，再执行关闭／呼唤；新的回调在锁释放后属于新在场集合。磁盘保存放在输入锁外，避免阻塞原生计数回调。

被拒绝的过期命令仍保留此前已经结算的收益；普通统计／倒计时快照不会使正在提交的 UI 动作无谓失效，但命令及语义转换会阻止旧状态覆盖。前端失败后刷新，不自动重试动作。

存档失败时，一般动作保留已生效的内存状态并显示存储警告，不能声称已保存；最后一人关闭失败会在另一输入边界恢复原在场状态并取消退出。关闭最后一人成功后停止输入监听并退出。

6. 将专注设为5分钟、休息1分钟，开始一轮；设置页关闭不应停止计时。检查休息站立／提示、暂停恢复及默认等待下一轮。
