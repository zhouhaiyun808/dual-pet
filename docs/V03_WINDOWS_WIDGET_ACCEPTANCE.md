## 4. 结果与停止标准

- 结果只填 `PASS`、`FAIL` 或 `BLOCKED`；`BLOCKED` 必须记录环境或权限原因。
- 出现崩溃、无法退出、窗口丢失无法恢复、输入数据明显错误或按钮热区大面积偏移时，停止扩大测试并先报告。
- 每个 `FAIL` 至少附：用例编号、系统与缩放比、复现步骤、预期／实际、截图或录屏；若闪退，再附应用事件日志。
- 只有 WIN-01–18 全部 `PASS`，且已完成至少一组 Windows 100% 缩放比时，才可将本轮 Windows 核心功能标记为验收通过。WIN-19–21 按可用环境执行并明确记录。
