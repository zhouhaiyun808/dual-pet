# 设置页还原阶段 · 2026-09-17

本阶段按纵向效果图重组设置页：陪伴／专注／成长／设置四个真实页签，默认专注。专注包含倒计时、分段进度、今日陪伴、双方独立键鼠次数。旧设置、收藏、权限与成长详情保留在相应页签。切页不卸载监听，不重置计时器，不丢失设置草稿。

连续阶梯边框、玉绿按钮双线、角花、键鼠 icon 使用本地 SVG/CSS；数字由本地像素字形绘制，不依赖平台字体。中文标题保留系统宋体。陈子奚采用现有正面行走首帧，人物显示复用桌宠的图集边线清理。江晏金燕补全裁切，只有燕子本体，无流苏、珠子或连接件。

两颗角色心形组表示当前阶段亲密度相对目标的真实进度，不固定填满效果图中的四颗心。键鼠次数、在场状态和活动均来自现有快照／实时计数。窗口仍为默认 620×760、最小 400×480，小窗口纵向滚动，不强制放大原生窗口。保留原生系统窗口栏，没有模拟不可操作的关闭或最小化按钮。
