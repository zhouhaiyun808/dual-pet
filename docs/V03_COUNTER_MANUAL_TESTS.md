# V0.3 面板与成长来源手工测试

本轮只覆盖桌面计数面板入口、成长来源展示与离场规则。成长页将“操作次数”和“今日收益”分开显示；以下“模拟”仅用于验证界面和状态映射，模拟输入不等于真实键盘/鼠标采集；真实采集仍需在用户明确授权后，于真机按实际设备验证。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| C01 | 在成长页点击“打开桌面计数面板” | 调用 `open_counter`，出现实时桌面计数面板；返回成长页后状态仍可刷新 |
| C02 | 关闭输入计数，观察成长页 | 键盘/点击计数关闭；既有成长不被清零 |
| C03 | 使用测试状态提供一组 `dailySources` | 两位人物分别显示陪伴、键盘、点击、番茄钟、未分类五类每日收益；陪伴包含清醒与宠物睡眠基础收益，键鼠来源以状态中的后端实际收益为准 |
| C04 | 使用没有 `dailySources` 的旧存档 | 陪伴/键盘/点击显示 0；`dailyEarned - dailyFocusEarned` 显示为未分类，表示本版本前无法追溯来源的历史；不根据操作次数倒推，也不表述为收益丢失 |
| C05 | 让人物离场，再等待一段时间并刷新 | 进度保留；离场期间收益暂停，不出现呼唤后的离场补算 |
| C06 | 使用带有 0.1、0.2、0.3 的浮点测试状态 | 未分类不出现 `-0.0` 或极小负数 |
| C07 | 用 Core 的临近上限真实批次结算流程（含混合键鼠批次）后观察展示 | 有效键鼠收益按占比分摊，后端原先总额不变；页面总额按 800 上限展示，来源项保留两位小数；不要向实际存档注入超过 800 的状态，超上限仅由纯 helper 防御测试覆盖 |
| C08 | 在无输入权限的环境点击权限按钮 | 页面清楚显示权限/监听状态；不要把模拟注入或历史次数当作真实采集成功 |
| C09 | 打开桌面计数面板，隐藏面板，再次点击入口 | 面板可重新显示；同一时刻只有一个面板实例，不重复创建窗口 |
| C10 | 从成长页点击入口后观察当前应用焦点 | 面板在后台打开，不抢当前用户焦点 |
| C11 | 分别给两位人物准备不同的每日收益状态 | 两张成长卡分别显示各自的五类收益；两位人物的收益不会相加后显示在任一人名下 |

## 记录

- 面板入口和成长分类的页面行为可用状态模拟检查。
- C09–C11 的隐藏重开、单实例、后台不抢焦点和人物隔离需要真机手工确认。
- 真实键盘、鼠标采集、权限弹窗、离场暂停的最终确认必须在目标桌面环境手工完成；本文件不包含 UI 自动化真机测试。
